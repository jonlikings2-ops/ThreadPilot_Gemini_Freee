    05 · AI connection

    OPTIONAL BACKEND

    To enable live AI chat and screenshot-based solving, start the included Node.js backend. Do not paste an AI provider secret key into this page. The endpoint should keep secrets server-side.

    On the hosted website, AI connects automatically when the server has an API key.
    Included backend routes
    • POST /chat — { message }
    • POST /train — written rules (video analysis not supported)
    • POST /solve — screenshot image; returns { moves: [], explanation }
    • POST /play — returns unsupported until a control bridge is installed
    • POST /stop — stop an active play sequence
    • GET /health — connection test
    AI screenshot interpretation is experimental and may not find a valid solution. An AI backend is included separately. Automatic gameplay and video analysis still need additional integrations. No move is executed unless a connected backend explicitly supports it.
